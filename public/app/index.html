TT Gate

Face attendance terminal · The Tamarind Tree

For the gate iPad only. Everyone else should use the web app.

Install TT Gate

This iPad must be registered first. Apple only allows an app outside the App Store onto devices that were named when it was built. If you have not sent us this iPad's identifier, the install will fail with “Unable to Install” and nothing else.

To register it: connect the iPad to a Mac, open Finder, click the iPad, then click under its name until the identifier (UDID) appears — click it and copy, then send it to IT.

Do I need this app at all?

Only if this iPad runs iOS 12. On iOS 12 Safari can open the gate in a tab, but the camera stops working the moment it is added to the Home Screen — so the app is the only way to get a proper full-screen terminal on that hardware.

On iOS 13.4 or newer you do not need this. Open tt-hrms.vercel.app/kiosk in Safari and use Share → Add to Home Screen. Same terminal, nothing to install, updates by itself.

After it installs

  1. Open TT Gate from the Home Screen.
  2. Allow the camera when asked. Attendance cannot be recorded without it.
  3. Pair the terminal once, using the code from /admin/kiosk/devices. It stays paired after that.
  4. The first launch downloads about 6 MB of recognition models. Do that on Wi-Fi before mounting it on the wall.

If the install fails

  • “Unable to Install” — this iPad's identifier is not registered. See the note above.
  • “Untrusted Enterprise Developer” — go to Settings → General → VPN & Device Management, tap the developer, then Trust.
  • Nothing happens when you tap Install — you are not in Safari. Open this page in Safari; other browsers on iOS cannot start an install.

Installs from this page are for The Tamarind Tree's own devices. The app does nothing on its own — it opens the same gate terminal as the website, and every scan is checked by the server exactly as it is in a browser.
